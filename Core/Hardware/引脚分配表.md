# LIGHTROBOT 引脚分配表

## 烧录接口
| 引脚 | 功能 |
|------|------|
| PA13 | SYS_JTMS-SWDIO |
| PA14 | SYS_JTCK-SWCLK |

## USB OTG
| 引脚 | 功能 |
|------|------|
| PA11 | USB_OTG_FS_DM（差分负数据线） |
| PA12 | USB_OTG_FS_DP（差分正数据线） |
| PA10 | USB_OTG_FS_ID（主机/从机识别） |
| PA9  | USB_OTG_FS_VBUS（供电检测） |

## I2C
| 外设 | SCL | SDA | 用途 |
|------|-----|-----|------|
| I2C1 | PB6 | PB7 | 陀螺仪 |
| I2C2 | PB10 | PB11 | OLED |
| I2C3 | PA8 | PC9 | 颜色传感器（TCS34725） |

> ⚠️ PA9 是 USB_OTG_FS_VBUS，不是 I2C3_SDA，I2C3_SDA = PC9。

## USART
| 外设 | TX | RX | 用途 |
|------|----|----|------|
| USART2 | PD5 | PD6 | 预留 |
| USART3 | PD8 | PD9 | 预留 |
| USART6 | PC6 | PC7 | 8 路灰度循迹 |

## 舵机（TIM5 / TIM9）
| 通道 | 引脚 | 定时器 | 说明 |
|------|------|--------|------|
| 舵机1 | PA0 | TIM5_CH1 | SERVO1 |
| 舵机2 | PA1 | TIM5_CH2 | SERVO2 |
| 舵机3 | PA2 | TIM5_CH3 | SERVO3 |
| 舵机4 | PA3 | TIM5_CH4 | SERVO4 |
| 舵机5 | PE5 | TIM9_CH1 | SERVO5 |
| 舵机6 | PE6 | TIM9_CH2 | SERVO6 |

## 步进电机 / 丝杆滑台
| 设备 | DIR | STEP | PWM通道 | 类型 | 驱动方式 | 用途 |
|------|-----|------|---------|------|----------|------|
| 电机1 | PA7 | PA5 | TIM2_CH1 | 42步进（张大头） | PWM脉冲 | 小车左轮 |
| 电机2 | PC4 | PA6 | TIM3_CH1 | 42步进（张大头） | PWM脉冲 | 小车右轮 |
| 电机3 | PD11 | PD12 | —（GPIO） | 42步进（张大头） | 软件脉冲（DWT） | 丝杆滑台 |

### 丝杆滑台物理参数
| 项目 | 值 |
|------|-----|
| 丝杆型号 | 1610（导程 10mm/圈） |
| 行程 | 100mm |
| 步进分辨率 | 0.05mm/步（全步 1.8°）|
| 步/mm | 20（= 200步/圈 ÷ 10mm/圈）|
| 脉冲方式 | 软件 GPIO 脉冲（PD12） |
| 速度控制 | `step_period_us`（周期=速度，250μs ≈ 200mm/s）|
| 控制 API | `Motor3_MoveDistance(mm, step_period_us)` |
| 绝对定位 | `Motor3_MoveToMM(target_mm, period)` |
| 回零 | `Motor3_Home(period)` |

## 驱动文件映射
| 模块 | .h | .c | 接口 |
|------|----|----|------|
| 电机 | motor.h | motor.c | Motor1/2/3_SetSpeed(speed) |
| 舵机 | servo.h | servo.c | Servo1~6_SetAngle(0~180) |
| 颜色 | tcs34725.h | tcs34725.c | I2C3, TCS34725_ReadColor() |
| 循迹 | huidu.h | huidu.c | USART6, 8路权重 → 电机速度 |
| 动作 | dongzuo.h | dongzuo.c | 组合动作序列 |
